# 颜色判定

按以下三条判定颜色：

- 无标记：官网原文直接摘录，且页面明确写了目标入学周期。
- 🟠 橙（建议二次核对）：官方页面，但有推断空间——页面没写周期年份、措辞为“通常/typically/normally”、多页面表述不一致、数据超过一年。
- 🔴 红（需人工检查）：查不到官方来源；官方页面互相矛盾；**硬门槛类字段没拿到当年页面**。

硬门槛字段固定清单：截止日、必修/指定科目、A-level 档位、标化要求、是否笔试、是否面试、国际生英语要求、先修课程。

最大风险：年份错位（官网挂着上一届页面）。每个字段必须核对页面声明的周期。

## 年份错位检查

1. 先把画像中的 `target_intake` 写成明确年月；澳洲默认 `2028-02`，其余默认值见各国参考文件。
2. 每打开一个页面，查页面标题、正文、表格标题和 PDF 页眉中的入学年份、学年、学期；记录页面自身声明的周期，不把抓取日当作周期。
3. 对照目标 intake。只有明确对应目标周期的官网原文才可能无标记；硬门槛页面没有当年周期，必须 🔴。软字段未写周期、旧数据等按上述橙色规则处理。
4. 同字段跨页面核对；若内容直接互相矛盾，🔴 并列两版及各自来源。对表达不一致但是否构成矛盾无法判定的情况，在该字段的标记原因里写明疑点，并标 🔴。
5. 无正文、需登录或 JS 渲染导致无法读取时，记录 🔴“无法读取”；不得用别处或记忆补事实。

## 判定练习

以下全部是**虚构的 Example University 情境**，仅用于判断颜色；没有来源 URL，不能作为档案事实字段。

| 情境 | 颜色 | 原因 |
|---|---|---|
| Example University 官网页面明写 `2027 entry`，某软字段有连续原文摘录，目标为 2027 入学 | 无标记 | 官方原文且页面明确对应目标周期；正式落盘仍需 URL 与抓取日。 |
| Example University 官网课程结构页未写入学年份 | 🟠 | 官方页面未声明周期，课程结构可能变化。 |
| Example University 官网 `2027 entry` 页面写 `normally`，描述某项申请材料 | 🟠 | 虽有当年页面，措辞仍留推断空间。 |
| Example University 的往年统计表标注两年前的数据 | 🟠 | 数据超过一年，必须注明数据年份。 |
| Example University 两个官方页面对某非硬门槛字段措辞不同，但尚不能判定直接矛盾 | 🟠 | 多页面表述不一致，需要二次核对；若实为互斥内容则转 🔴。 |
| Example University 的当年官方页面和另一当年官方页面对是否笔试给出相反结论 | 🔴 | 官方页面互相矛盾，必须并列两个版本。 |
| Example University 的 A-level 档位只在上一届页面可读，目标为下一届 | 🔴 | 硬门槛字段没拿到当年页面；旧要求不能冒充当年要求。 |
| 搜不到 Example University 关于先修课程的官方说明 | 🔴 | 查不到官方来源，写“未核实”，不能推断为“无先修”。 |
| Example University 的费用 PDF 无法提取正文 | 🔴 | 无法读取原文，不能转述为已核实事实。 |

上述例子中，只有具备连续英文原文、官方 URL、抓取日期的事实才能落盘。未找到的字段仅写红色“未核实”占位。
