# 档案字段

`schools/*.md` 与 `programs/*.md` 分开；每个事实字段都使用下述固定证据块。典型出处只是**页面类型**，不是可替代的来源。每次都要核对目标 intake。

## 证据块格式

每个事实字段用一个三级标题和一组固定条目。以下为格式占位，不含学校事实或示例 URL；方括号内容须替换为实际证据，`YYYY-MM-DD` 须替换为实际抓取日期。

```markdown
### 【字段名】 🟠
- EN: "【页面上的一段连续英文原文】"
- 中: 【与原文对应的中文翻译】
- 来源: 【实际打开的官方页面 URL】
- 页面声明周期: 【页面原文声明的入学周期；未写则填 —】
- 抓取: YYYY-MM-DD
- 标记原因: 【需要核对的具体疑点，一句话】
```

- 无标记时，标题后不加 emoji，并省略“标记原因”条目；🟠 或 🔴 放在标题末尾，且必须写“标记原因”。颜色判断见 `color-rules.md`。
- `EN` 必须用英文双引号包住页面原文的连续摘录，不得改写或拼接；“中”只翻译对应原文。已核实事实须同时有原文引号、官方 URL 和抓取日期，缺任一项只能写“未核实”。
- “页面声明周期”记录页面实际写明的周期，不能用抓取日期代替；硬门槛没有目标周期页面时必须 🔴。

未找到官方来源时固定写法如下；“抓取”填写本次尝试查找的实际日期：

```markdown
### 【字段名】 🔴
- EN: —
- 中: 未核实
- 来源: —
- 页面声明周期: —
- 抓取: YYYY-MM-DD
- 标记原因: 未找到官方来源
```

费用、往年数据同样使用上述证据块；往年数据还必须明确写出数据年份。文化与校园单独成栏，标题固定为 `### 文化与校园（学校自述，非客观评价）`，不得混入事实字段。

## 学校层 `schools/`

| 字段 | 定义 | 硬门槛 | 典型出处页面类型 |
|---|---|---|---|
| 官方域名 | 用户确认的学校主域名；存 frontmatter | 否 | 学校官网首页或官方机构目录，仍须用户确认 |
| 所在地与类型 | 校区所在地、院校类型，按页面所指层级记录 | 否 | 学校概览、官方统计机构的学校页 |
| 通用申请流程与申请系统 | 该校适用的申请入口和基本流程；具体课程例外另记 | 否 | 招生办申请指南、官方申请系统说明 |
| 国际生英语要求 | 国际申请者语言考试、豁免或最低标准；不把通用英语说明套到所有课程 | **是** | 国际本科招生/英语要求页 |
| 费用 | 学费及其适用学年、身份、校区和币种；不推算总成本 | 否 | 官方学费表、收费政策页 |
| 奖学金入口 | 仅记录官方入口链接及适用对象的原文 | 否 | 学校奖学金索引页 |
| 文化与校园（学校自述，非客观评价） | 学校对校园生活的自我描述，单独成栏 | 否 | 学校校园生活或概览页 |

## 课程层 `programs/`

| 字段 | 定义 | 硬门槛 | 典型出处页面类型 |
|---|---|---|---|
| 课程全名、学位、学制、目标 intake | 课程正式名称、授予学位、正常学制和拟入学年月 | 否 | 当年课程目录、项目招生页；intake 同时写 frontmatter |
| A-level 档位 | 该课程公布的 A-level 等级/组合要求 | **是** | 当年课程入学要求页、官方招生 PDF |
| 必修/指定科目 | 对科目及科目等级的明确限制 | **是** | 当年课程入学要求页 |
| 是否笔试 | 是否要求入学考试、考试名称及适用范围；不把“未提”当“无需” | **是** | 当年课程申请流程、考试说明页 |
| 是否面试 | 是否面试、对象和形式；不把“未提”当“无需” | **是** | 当年课程申请流程、面试说明页 |
| 截止日 | 对该课程、申请人身份和目标 intake 适用的提交日期及时间/时区 | **是** | 当年官方申请日历、课程页 |
| 标化要求 | SAT/ACT 或同类考试的要求、可选/豁免状态及适用范围 | **是** | 当年本科招生考试政策页 |
| 先修课程 | 入学前必须完成的课程或资格，区别于建议背景 | **是** | 当年课程先修要求页 |
| IB/AP 等体系认可 | 是否认可及适用条件；不把认可等同具体门槛 | 否 | 官方国际资格对照页 |
| 往年数据 | 录取率、offer 率或典型分数；仅当原始官方数据有对应指标和明确年份时写，缺则红色留空，不估算 | 否 | UCAS/HESA/CDS 或已获批准的官方统计入口 |
| 课程结构 | 模块/课程安排的简短中文摘要及官方链接 | 否 | 官方课程结构页、课程手册 |

各国差异见 `uk.md`、`us.md`、`au.md`、`ca.md`。美国只有官方说明直录学院或专业时才建课程层；否则仅建学校层。
