# 美国 US

## 申请周期与系统

- 默认目标 intake：`2027-09`；用户可修改。以学校官方招生页说明的申请方式与轮次为准，不设全国统一截止日。
- 只有官方确认直录工程、CS、护理等学院或专业时才建立课程层；其余只建学校层。申请系统可能由学校自有入口或其指定平台承载，具体入口必须从已确认学校域名核验。
- 各校 Common Data Set 仅在学校官方域名发布且正文可读时可用；历史统计不可直接当目标周期的录取概率或课程门槛。

## 笔试与面试常见形态

分开核对考试政策与面试政策，留意申请轮次、申请人类别和学院差异。`test-optional` 只按官方当年页面的适用范围记录，不能扩写成所有申请人都免交。

## 术语

| 英文 | 在档案中的含义 |
|---|---|
| test-optional | 某类标化成绩可选择提交；须记适用周期与对象 |
| required / recommended | 必须 / 建议；不能互换 |
| early / regular | 不同申请轮次；截止日、材料和政策须分别核对 |
| Common Data Set (CDS) | 学校发布的统计表；须记数据年份、群体和指标定义 |

## 年份错位陷阱

学校招生总页、学院页、考试政策页和 CDS 往往属于不同年度。先比对目标 intake，再核对页面或 PDF 的年份；旧周期硬门槛 🔴。CDS 的历史统计即使最新发布，也不是当年申请要求。
